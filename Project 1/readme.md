# Project 1 Responsive Frontend Interface

My Week 1 submission for the DecodeLabs Full Stack internship.

# What I built

A fully responsive webpage using only HTML, CSS, and JavaScript.
No frameworks used at all.

# Features

- Sticky navbar with mobile hamburger menu
- Animated hero section with floating cards
- Features grid with hover effects
- Animated stat counters triggered on scroll
- Contact form with validation
- Scroll reveal animations throughout

# How to run
Just open index.html in any browser. No setup needed.
