# Project 2 - Backend API Development

My Week 2 submission for the DecodeLabs Full Stack internship.

## What I built
A REST API using Node.js and Express with full CRUD endpoints.

## How to run
npm install
node index.js

Server starts at http://localhost:3000

## Endpoints
 GET  /api/users
 POST /api/users
 GET  /api/products
 POST /api/products
 POST /api/contact

## What I learned
How routes work in Express, why you separate them into different
files, and why server side validation matters more than frontend
validation.
